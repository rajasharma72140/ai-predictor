# AI Predictor — Android prototype

This is the first UI prototype for an EUR/USD 1-minute prediction app.

## Run
1. Install Flutter SDK and Android Studio.
2. Extract this project.
3. Open the folder in Android Studio or VS Code.
4. Run:
   flutter pub get
   flutter run

## Current status
- Android UI: ready
- EUR/USD selector display: ready
- 1-minute timeframe display: ready
- UP/DOWN/NO TRADE display: ready
- Demo prediction button: ready
- Real market data: not connected yet
- ML model: not connected yet

The demo prediction is intentionally not a real trading signal.
